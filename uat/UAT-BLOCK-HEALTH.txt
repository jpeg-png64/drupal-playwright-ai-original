HOW TO MANUALLY ACCESS THE ERRORS
=================================
1. Open https://builder-clean.docker-uat01.ust.hk and log in as admin
   (CAS / drush uli).

2. Reproduce a 500 (shows only a generic page):
   - /admin/event-registration/overview -> "The website encountered an
     unexpected error. Try again later."
   - /admin/config/people/otp -> same generic message.

3. See the real exception - Recent log messages:
   - Toolbar -> Reports -> Recent log messages  (URL: /admin/reports/dblog)
   - Filter to PHP errors: /admin/reports/dblog?type[]=php -> rows like
     "ArgumentCountError: Too few arguments to function..." and
     "TypeError: ksort(): Argument #1 ($array) must be of type..."
   - Click the event link to open /admin/reports/dblog/event/{eid} for the
     full Message, Location, Referrer and Operations (View / Re-run).

4. See the 404s (page-not-found warnings):
   - /admin/reports/dblog?type[]=page+not+found -> every 404 (e.g. /people,
     /admin/config/people/rac/relations, /quickedit/metadata) with the
     Location (requester) and Referrer.

5. Module status (explains disabled-module 404s):
   - /admin/modules -> e.g. "Quick Edit" and "Role Access Control Relations"
     are unchecked (disabled).

Note: this build does NOT display errors on the page itself (generic
"unexpected error" page only). The dblog is the source of truth for the
actual exception message.
